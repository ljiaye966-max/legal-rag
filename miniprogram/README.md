# AI 法律案例推理系统微信小程序端

## 导入微信开发者工具

1. 启动后端：运行最新项目文件夹中的后端服务，并让它监听局域网地址。
2. 打开微信开发者工具，选择“导入项目”。
3. 项目目录选择当前 `miniprogram` 文件夹。
4. 开发阶段可使用“测试号”或保留 `touristappid`；有自己的小程序 AppID 后，将 `project.config.json` 中的 `appid` 替换为真实 AppID。
5. 本地调试时，在开发者工具的详情页关闭“不校验合法域名、Web-view（业务域名）、TLS 版本以及 HTTPS 证书”。

## 后端地址

开发者工具和同一 Wi-Fi 下的安卓真机默认读取：

```js
// miniprogram/utils/config.js
const API_BASE_URL = "http://10.53.31.3:8003";
```

如果电脑的 WLAN IPv4 地址发生变化，请修改该地址；后端需监听 `0.0.0.0:8003`。

安卓真机调试时，电脑和手机必须处于同一个 Wi-Fi，并确保 Windows 防火墙允许 Python/Uvicorn 访问专用网络。

正式发布不能使用局域网 IP 或 `127.0.0.1`。需要部署 FastAPI 后端到有 HTTPS 的公网域名，并在微信公众平台配置该域名为 request 合法域名，然后把 `API_BASE_URL` 改为该 HTTPS 地址。

## 已实现功能

- 账号密码登录与 Bearer session 登录态。
- 工作台和系统健康状态。
- 智能法律小助手：多轮追问、知识库检索、回答来源跳转和证据不足提示。
- 文档详情查看。
- 案情录入和后台 RAG 推理状态轮询。
- 推理结果、校验提示、引用来源、报告复制、反馈。
- 历史任务查看和删除。
- 类案选择与多维对比。
- 知识库管理员的文本知识库新建、编辑、删除。
- 系统管理员的 RAG 参数配置。

## 当前边界

- 小程序端的知识库管理暂支持文本录入；TXT、PDF、CSV、JSON 文件上传继续在 Web 管理端完成。
- 用户新增、停用和密码重置仍由 Web 系统管理页维护。
- 当前小程序使用后端账号密码登录，不包含微信授权登录；正式上线建议接入 `wx.login`、后端 `code2Session` 和用户绑定。
